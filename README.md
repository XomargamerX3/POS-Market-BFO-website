## 🖥️ متطلبات التشغيل باختصار

- Windows 10 أو 11 — **64-bit**.
- `.NET Framework 4.x` (مثبّت مع ويندوز — لا تثبيت إضافي).
- مجلد **قابل للكتابة** (لا تضعه في `Program Files` — البيانات تُحفظ بجانب البرنامج).
- شاشة 1366×768 أو أعلى (يفضّل 1920×1080).
- **بدون إنترنت** — الشبكة تُستخدم فقط لفحص التحديث التلقائي.
- اختياري: طابعة ويندوز (أو حرارية 58/80 مم) وماسح باركود USB.
